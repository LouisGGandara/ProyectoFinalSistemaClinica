# Sistema de atención y gestión de turnos

Aplicación de escritorio para una clínica: registra pacientes, genera turnos, los atiende en orden con una cola prioritaria y otra normal, y guarda un historial de acciones que se puede deshacer. Está hecha en Python con Tkinter y guarda los datos en archivos JSON.

## Requisitos

- Python 3.11 o superior (Tkinter viene incluido)
- No usa librerías externas

## Cómo ejecutarlo

Desde la carpeta del proyecto:

```
python main.py
```

## Pruebas

```
python -m unittest discover tests
```

Este archivo se completa en el paso F5 con los usuarios de prueba y la estructura de carpetas.
